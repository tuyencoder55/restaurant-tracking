# /tham-khao-giao-dien

Dùng khi mình gửi 1 link website (của người khác hoặc app khác) để tham khảo giao diện/luồng
thao tác, muốn áp dụng ý tưởng đó vào web quán ăn của mình.

Cần mình cung cấp: link, và muốn học phần nào (bố cục tổng thể, 1 màn hình cụ thể, cách
tương tác/animation, hay cả trang). Nếu mình chỉ gửi link không nói rõ, hỏi lại trước khi làm.

1. **Mở link bằng browser agent**, chụp screenshot (trang chính, và cả những màn hình/khu vực
   mình yêu cầu cụ thể nếu có, ví dụ: form thêm mới, trang chi tiết, bộ lọc...).
2. **Phân tích & tóm tắt** bằng tiếng Việt, ngắn gọn, những điểm hay đáng học theo nhóm:
   - Bố cục (layout): sắp xếp thành phần ra sao
   - Tương tác (interaction): cách lọc, chuyển trang, hiệu ứng
   - Phong cách thị giác (màu, khoảng cách, kiểu chữ, bo góc...)
   Chỉ ra rõ phần nào **phù hợp** để áp dụng cho web quán ăn (theo skill `thiet-ke-giao-dien`
   và rule `03-tinh-nang-cot-loi.md`), phần nào không phù hợp/không cần thiết.
3. **KHÔNG copy y nguyên** nội dung, ảnh, logo hay text của trang tham khảo — chỉ học bố cục,
   luồng thao tác và phong cách thiết kế. Nếu trang đó có yếu tố thương hiệu/bản quyền rõ ràng
   (logo, ảnh chụp riêng, nội dung viết riêng), nhắc mình biết để tránh dùng lại.
4. **Đề xuất áp dụng**: đưa ra 1 kế hoạch ngắn nên đổi/thêm gì trong component hiện có, và hỏi
   mình xác nhận trước khi code (đừng tự động code luôn nếu thay đổi ảnh hưởng nhiều màn hình).
5. Sau khi mình đồng ý, code theo, rồi chạy thử và chụp lại kết quả để so sánh với bản gốc.
